# Что нового

## 0.3.35

- Импорт ссылок INCY: `incy://crypt1/…` (открытый MIT-ключ), `incy://add/`, `incy://import/`, профили `incy://routing/…`.
- При загрузке подписки подхватываются routing-строки в теле и заголовки `routing` / `autorouting`.
- Для панелей INCY добавлен User-Agent `INCY/3.7.2` и заголовок `x-client`.
- `happ://crypt…` по-прежнему не расшифровывается.

## 0.3.34

- Исправлен запуск sing-box с DNS-профилем Happ (BlancVPN и др.): `geoip:private` больше не загружает несуществующий `geoip-private.srs` — используется встроенное правило `ip_is_private`.

## 0.3.33

- Исправлена загрузка rule-set (geoip/geosite) в sing-box 1.14: убран `http_client.detour: direct`.

## 0.3.32

- Исправлен запуск sing-box 1.14 с DNS-профилем: убран недопустимый `detour: direct` у DNS-серверов.

## 0.3.31

- Исправлен запуск sing-box 1.14 с DNS-профилем Happ: `dns.hosts` заменён на сервер `type: hosts`.

## 0.3.30

- Исправлено автообновление при активном VPN: GitHub идёт напрямую, без туннеля.
- При ошибке SSL обновление повторяется после отключения VPN.
- Загрузка ядер и релизов приложения больше не использует системный прокси Windows.

## 0.3.29

- Импорт DNS-профилей Happ из буфера: `happ://routing/add/…` (DoU, DoH, FakeDNS, DnsHosts).
- Выбор DNS-профиля в главном окне; меню «Маршрутизация» для импорта и удаления.
- sing-box: FakeDNS, DoU/DoH/DoT, кэш rule-set, исправлен `download_detour` → `http_client`.
- Более надёжная проверка туннеля после старта (ожидание mixed-порта, повторные пробы).
- Автопереход на Xray без TUN, если Reality/Vision не отвечает через sing-box TUN.

## 0.3.28

- Исправлена загрузка подписки при активном TUN или системном прокси.
- Убран принудительный обход VPN для панели подписки, из-за которого HTTPS мог сбрасываться.
- Исправлена маршрутизация служебных запросов через рабочее подключение.

## 0.3.27

- Исправлена загрузка подписки: запрос идёт напрямую, без системного прокси Windows.
- При ошибке SSL/TLS показывается понятная подсказка (отключить VPN/прокси и повторить).
- В режиме TUN хост панели подписки обходит туннель, чтобы обновление работало и при подключении.

## 0.3.26

- Сведения о подписке показываются прямо в главном окне.
- Добавлена кнопка «Обновить подписку» в блоке сведений.
- Отдельное окно «Подробнее о подписке» удалено.

## 0.3.25

- Окно приложения больше не скрывается в трей при запуске.
- При включённой настройке окно скрывается в трей только после закрытия или сворачивания.

## 0.3.24

- Ручное отключение больше не запускает отложенное автоматическое переподключение после события сети.

## 0.3.23

- Исправлен User-Agent подписки: приложение больше не представляется как Hiddify или другой сторонний клиент.
- Для совместимости с Remnawave используется идентификатор обычного клиента `Happ/3.3.6`.

## 0.3.22

- Подробные сведения о подписке: профиль, расход и остаток трафика, срок действия в днях, серверы и время обновления.
- Исправлена гонка при одновременной остановке sing-box/Xray.
- Обычный лог sing-box переведён в режим предупреждений, чтобы запись каждого соединения не замедляла TUN.
- Повторяющиеся endpoint’ы учитываются один раз при проверке списка серверов.

## 0.3.21

- Добавлен пункт «Справка → Что нового в версии».
- Список изменений загружается со страницы GitHub Release и доступен без установки браузера.
- Улучшена диагностика причин медленной работы серверов.

## 0.3.20

- Добавлена очистка временных файлов после portable- и Setup-обновления.
- Усилено восстановление сессии, kill switch и безопасное хранение локальных данных.
- Исправлены обработка JSON-подписок, WS/gRPC и IPv6 Shadowsocks.

## 0.3.19

- Исправлены гонки восстановления сессии и остановки ядер.
- Добавлена проверка свежести AmneziaWG handshake.
- Изменения настроек подключения теперь применяются через переподключение.

## 0.3.18

- Убрана ложная перезагрузка из-за необязательной DNS-over-HTTPS проверки.
- Добавлена защита от двойного восстановления после завершения ядра.
